# ADR 0001: Essential tools

Статус: принято, 0.1.0.

1. Каноническое имя пакета `twylt-pack-essential`; имена команд соответствуют запросу: echo/sleep/wget/curl/ping/web_search.
2. Общая реализация генерируется внутрь самостоятельных tool.py по соглашению twylt-pack-filesystem. Статические метаданные доступны загрузчику TWYLT даже при отсутствии бизнес-зависимостей.
3. Для HTTP используется urllib: меньше зависимостей и одинаковые контракты на Linux/Windows. Семантика wget/curl ограничена явно описанным HTTP API. ICMP использует системный ping без shell, поскольку raw ICMP требует платформенной поддержки и разрешений.
4. Поиск через JSON API SearXNG с сервером из доверенного окружения. Нет хрупкого HTML-скрейпинга и автоматически выбранного публичного сервера.
5. Загрузки ограничены объёмом, атомарно публикуются в workspace. Перенесена текущая политика файлового пака; это не полноценная OS sandbox. Сеть имеет общий запрет через окружение, HTTP допускает адреса локальной сети.
6. HTTP ошибки представлены статусами; ошибки исполнения передаются штатным JSON-протоколом TWYLT. sleep ждёт реально, длительность измеряется monotonic.
7. Ответы HTTP буферизуются, что упрощает единый bounded-контракт и сохранение существующих файлов при ошибке. Потоковая запись больших загрузок оставлена будущей версии.

Дополнение 0.1.1: echo возвращает обязательную строку text без преобразований; работает независимо от сетевой политики.
