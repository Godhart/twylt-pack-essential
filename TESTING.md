# Проверка 0.1.1

Команда: `python -m unittest discover -s tests -v`.

17 тестов: реальное ожидание; ограничения и неизвестные поля; HTTP текст/бинарные данные; POST JSON; статусы ошибок; редиректы, включая запрет file:// и удаление секретов при смене origin; атомарная запись и запрет перезаписи; сохранность файла при превышении лимита и HTTP ошибке; workspace traversal и symlinks; выключение сети; запросы и нормализация SearXNG; системный ping (mock успешного результата, отказа, тайм-аута и отсутствия утилиты); метаданные и few-shots всех шести standalone-инструментов; CLI/stdin и JSON ошибки TWYLT.

Все тесты прошли на Python 3.12 / Pydantic 2.13.5 / TWYLT 1.0.0. Тесты не обращаются к внешним серверам; реальная выдача SearXNG и ICMP-запуск в Docker/Windows здесь не проверялись.

Добавлены проверки echo: пустая строка, Unicode, пробелы, CRLF, табуляция и NUL; ошибки отсутствующего/нестрокового text и лишних полей; реальный CLI при выключенной сети.
